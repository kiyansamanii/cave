# CAVE — BACK INTO THE DEPTHS

Personal offline academic tracker (Persian RTL). A single standalone `index.html` — no server, no build, no internet needed.

- Open `index.html` directly in Chrome/Edge, or host it with GitHub Pages.
- All data stays in your own browser (localStorage). Nothing is sent anywhere.
- Back up regularly: Settings → JSON export.
- Windows desktop icon: keep `index.html`, `CAVE.ico` and `Create-CAVE-Shortcut.bat` in one folder and run the `.bat`.

Font: Estedad (embedded as Base64) — see its own license.
